Connect your GitHub account

Allow access to GitHub. Your browser hasn't let the extension work on github.com yet, so the Actions button and the All actions page can't appear.

  1. Choose how to connect

    Sign in with GitHub Recommended

    Approve read-only access on GitHub by entering a code, then pick which repositories to watch. No token to create or renew.

    Use a read-only token

    Opens GitHub with the name and two read-only permissions filled in: Actions: Read to see your runs, and Contents: Read to read each workflow's schedule so the extension can tell when one didn't run. Choose your repositories and click Generate token.

    Open GitHub's token page ↗

    Paste a new token to replace it, or disconnect below and sign in with GitHub instead.

  2. Finish connecting

    Made a token? Paste it here.

    Enter this code on GitHub to approve the sign-in. The button below copies it for you.

    Open github.com/login/device ↗

    Waiting for you to approve on GitHub…

    Now choose your repositories. Pick All repositories or just the ones you want watched, then come back here.

    Choose repositories on GitHub ↗

    This token can't read workflow files, so workflows that didn't run can't be spotted. Edit it on GitHub and add Contents: Read under Repository permissions. The token itself stays the same.
