Connect your GitHub account

Allow access to GitHub. Your browser hasn't let the extension work on github.com yet, so the Actions button and the All actions page can't appear.

The extension reads your workflow runs with a read-only token. The token stays in this browser and is only sent to api.github.com.

  1. Create a read-only token

    This opens GitHub with the name and two read-only permissions filled in: Actions: Read to see your runs, and Contents: Read to read each workflow's schedule so the extension can tell when one didn't run. Under “Repository access”, choose All repositories or just the ones you want watched, then click Generate token.

    Already connected with an older token? You don't need a new one. Edit it on GitHub ↗, add Contents: Read under Repository permissions, and save. The token itself stays the same.
